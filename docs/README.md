# Documentação

Este diretório reúne a documentação técnica que evolui junto com o projeto.

## Conteúdo

- [ADRs](adr/README.md): decisões arquiteturais e seus trade-offs.

## Princípios

- Registrar decisões relevantes antes ou no momento em que forem implementadas.
- Manter cada documento curto, objetivo e versionado com o código.
- Atualizar o status de um ADR quando uma decisão for aceita, substituída ou rejeitada; não reescrever seu histórico.
