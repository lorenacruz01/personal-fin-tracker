# Documentação

Este diretório reúne a documentação técnica e de produto que evolui junto com o projeto.

## Conteúdo

* [ADRs](adr/README.md): decisões arquiteturais e seus trade-offs.
* [PRDs](prd/README.md): requisitos, escopo e comportamento esperado do produto.

## Princípios

* Registrar decisões arquiteturais relevantes antes ou no momento em que forem implementadas.
* Documentar requisitos e escopo antes do desenvolvimento das respectivas funcionalidades.
* Manter cada documento curto, objetivo e versionado com o código.
* Manter a documentação alinhada ao estado atual do projeto.
* Preservar o histórico de decisões arquiteturais quando uma decisão for substituída ou rejeitada.
